# art/

For illustration, character art, scene sketches, diagrams — anything visual.

## What's wanted

- Character art for anyone in `story/characters/` or the main cast
- Key scene illustrations for any episode in `story/episodes/`
- Anything visual that helps someone else picture the season

## What's not required

- A particular style — whatever you draw in is fine
- Finished work — sketches and WIPs are genuinely welcome; see
  `CONTRIBUTING.md`'s note to newcomers, it applies here too

## How to contribute

- Comfortable with git? Add your file here (PNG/JPG/etc, keep it to a few
  MB) and open a PR. Name it something identifiable, e.g.
  `isla-ep12-ferriswheel.png`.
- Not comfortable with git? Open an Issue, describe or link the piece, and
  someone can help get it in. This is exactly the kind of thing
  `CONTRIBUTING.md` means when it says nothing here requires you to
  already know how any of this works.
